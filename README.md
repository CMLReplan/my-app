# React Reservation App

A responsive React application that allows users to reserve a table through an interactive booking form. This project was built with Create React App and deployed using Vercel.

## 🚀 Live Demo

🔗 https://my-app-phi-eight-47.vercel.app

## 🧠 Features

- Interactive reservation form where users can select date, time, guests, and submit a booking
- Responsive layout for desktop and mobile
- Built with React components and state management
- Deployed live using Vercel

## 🛠️ Tech Stack

| Technology | Purpose |
|------------|---------|
| React      | UI library |
| JavaScript | Logic and interactivity |
| CSS        | Styling |
| Vercel     | Deployment |
